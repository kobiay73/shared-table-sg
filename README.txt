BEFORE A PUBLIC SEO LAUNCH
1. Remove the noindex meta tag from every HTML page.
2. Change robots.txt from "Disallow: /" to the production crawling rules.
3. Confirm the final brand/domain and replace the placeholder email addresses.
4. Have cultural and restaurant details reviewed by appropriate sources and contributors.
5. Add analytics, Search Console verification, canonical URLs and an XML sitemap.
6. Replace or approve the included AI-generated demo photography.

The current package intentionally blocks search-engine indexing because it is a client preview.
